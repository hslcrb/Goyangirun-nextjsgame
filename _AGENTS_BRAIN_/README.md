# _AGENTS_BRAIN_ 디렉토리

**에이전트 세션 관리 및 프로젝트 지식 저장소**

---

## 📚 디렉토리 목적

이 폴더는 AI 에이전트가 프로젝트를 분석하고 작업한 내용을 세션별로 문서화하는 공간입니다.
각 세션마다 프로젝트 상태, 기술적 분석, 의사결정 과정 등을 기록하여:

1. **지속성**: 세션 간 컨텍스트 유지
2. **추적성**: 개발 과정 및 의사결정 기록
3. **학습**: 프로젝트 히스토리 및 패턴 분석
4. **협업**: 다른 에이전트/개발자와 지식 공유

---

## 📁 세션 구조

각 세션은 `sN/` 형태의 폴더로 구성됩니다 (N = 세션 번호).

```
_AGENTS_BRAIN_/
├── README.md              # 이 파일
├── s1/                    # Session 1
│   ├── session_init.md    # 세션 초기화 및 프로젝트 개요
│   ├── technical_analysis.md  # 기술 심층 분석
│   └── next_steps.md      # 다음 단계 및 제안사항
├── s2/                    # Session 2
│   └── ...
└── sN/                    # Session N
    └── ...
```

## 🎯 사용 가이드

### 에이전트용

**세션 시작 시**:
1. 최신 세션 폴더 확인
2. 이전 세션의 `next_steps.md` 리뷰
3. 새로운 세션 폴더 생성
4. `session_init.md` 작성

**세션 진행 중**:
- 주요 의사결정 기록
- 기술적 발견사항 문서화
- 문제 해결 과정 기록

**세션 종료 시**:
- `next_steps.md` 업데이트
- 세션 요약 작성
- 이 README 업데이트

### 개발자용

**프로젝트 이해**:
1. 최신 세션의 `session_init.md` 읽기
2. `technical_analysis.md`로 기술 이해
3. `next_steps.md`로 향후 계획 파악

**에이전트 협업**:
- 세션 문서를 통한 컨텍스트 공유
- 의사결정 히스토리 확인
- 작업 우선순위 파악
